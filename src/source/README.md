# Source Help Guilde
there is a short info about everysingle file in there:
  1.asmvia/qast.d: this file is not fully finished yet.
  2.asmvia/parser.d: like qast, this also not finished yet.
  3.asmvia: A simple Asmbley vitral for interperter to make ASM work in all device with diffrent cpu.
  4.box_p/header/ast.d: AST tree for #BOX block mode.
  5.box_p/header/parser.d: Parser for #BOX block mode.
  6.box_p: support box as block.
  7.csl/mempack/free.d: Free Defined here.
  8.csl/mempack/malloc.d: Malloc defined here.
  9.csl/preprs/_sbox.d: Support define box as a line.
  10.csl/preprs/define.d: support define uneditable strings or values.
  11.csl/preprs/sbox_funcprintf.d: function then they support box situation.
  12.clg/ultracgraphic/sgfu.d: an unfinised graphic support library for PSL
  13.cslm/proc.d:P/C (P/ for computer) IR Language, parser Direct executor.
  14.cslm/randomnameforvalue.d: Create random name for values like write("Hello"), it made hello as a string in ASM and made a random name for it. so it callable.
  15.header/ast.d: Header block AST tree.
  16.header/parser.d: Parser for header block.
  17.pslgrap/functions.d: PSL Ultra-beta graphical library.
  18.pslgrap/infssFunction.d: functions for use in interperter.
  19.app.d: Main point file. it handle args etc.
  20.ast.d: Unfinished ast tree for whole of PSL.
  21.error.d: Error printer and errors function.
  22.func.d: interperter-based functions. (write, return...)
  23.infss.d: main Interperter+parser.
  24.init_prog.d: old args manager.
  25.intfunc_fs.d: get user input function defined here.
  26.intfunc.d: unfinshed new tokenManager.
  27.lbrk.d: fi we get any } in tokens.
  28.math_manager.d: unfinshed math support functions.
  29.short.d: shortmode manager (Golfmode)
  30.ssm.d: function for exit app and print a message defined here.
  31.token_string.d: current tokenManager.
  32.ultracex.d: An old error method from UltraC.

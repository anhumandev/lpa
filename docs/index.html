Define first P/ Program

for a simple and quick hello world program, you have 2 way to do this job.

Standard Mode

generate main() {
   write("Hello world!\n");
}

Short Mode

~ "Hello world!\n"

generate

important keyword in P/, is generate . This keyword has no effect on behavior, return values, or any part of your code it simply signals to the interpreter that a definition is forthcoming.

This keyword is essentially used to define any kind of data or function:

define an int

generate int -v:inta = 23

Data

P/ supports multiple data types. However, at the time of writing this guide which corresponds to language version 0.0.2 alpha only a limited set of variable types are available.

Char(string) define

generate char -v:inta[] = "Hello world"

 (Note: you can also use --value , is short-mode of -v)

void* define

generate void* -v:inta

this will create a malloc-based space, as 1bit size.
